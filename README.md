## Favorites App Updated


As part of Assignment 3 in Mobile Application Development, this project focuses on applying 
state management and architectural principles in Flutter/Dart. The work builds upon the Favorites 
application from Module 3, and continues to develop the Favorites app by adding support for browsing categories, saving favorites, viewing favorite items, managing settings, and clearing saved favorites.

The following project goals were achieved:

- Completed the Hobbies category by displaying hobby names with corresponding icons and allowing users to favorite or unfavorite hobbies.
- Added the Books category using the provided book data and displayed each book with its title and author while supporting favorite functionality.
- Updated the Favorites screen to show all favorited items from every category in one location. With each category being color-coded.
- Allow users to remove favorited items directly from the Favorites screen, with changes reflected immediately throughout the app.
- Implemented category-based search filtering.
- Completed the Settings screen with theme preferences using local storage, so selections persist between app sessions.
- Added a Clear Favorites button with a confirmation dialog in the Settings and Favorites screens.
- Ensured favorite items stay synchronized across all screens and is saved when session ends.

**Note:** Before starting, run the following in your terminal:
```sh
flutter pub get
```
to download any additional dependencies for the project.
